Mozilla est le nom de code interne de Netscape : <i>Mosaic</i> + <i>Godzilla</i>, le monstre censé écraser le navigateur concurrent. Netscape s'annonce donc comme « Mozilla/1.0 ».

Netscape gère les frames, pas les autres. Les sites se mettent à tester la chaîne : si c'est Mozilla, j'envoie la belle version. Quand Internet Explorer sait faire les frames à son tour, il n'a pas le choix — il s'annonce « Mozilla/4.0 (compatible; MSIE) ».

Et ça n'a jamais cessé. Chrome se déclare comme Safari, qui se déclare comme KHTML, qui se déclare comme Gecko, qui se déclare comme Mozilla. La chaîne est un empilement de mensonges successifs que personne n'ose démonter.
