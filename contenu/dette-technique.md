Cunningham propose l'image pour justifier auprès de dirigeants le fait de livrer vite puis de remanier. Emprunter permet d'avancer maintenant ; les intérêts, ce sont les ralentissements futurs ; rembourser, c'est remanier.

Mais le sens qu'il visait n'est pas « du code sale qu'on nettoiera plus tard ». C'est l'écart entre ce que le code exprime et ce qu'on a <i>compris du problème depuis</i>. On écrit avec la compréhension du moment, forcément incomplète ; la dette naît quand la compréhension progresse et que le code ne suit pas.

Il l'a redit explicitement des années après, parce que la métaphore avait été retournée en permis d'écrire n'importe quoi. Dans sa version, du code bâclé n'est pas une dette : c'est juste du code bâclé, et on n'a rien emprunté du tout.
