Le noyau Linux perd l'accès à BitKeeper. Torvalds écrit son propre gestionnaire de versions en quelques jours, avec une obsession : la performance sur un dépôt énorme et l'impossibilité de corrompre silencieusement l'historique.

Pour le nom, il s'explique : « je suis un sale égocentrique, je nomme tous mes projets d'après moi-même » — après Linux, git. Le mot désigne en argot britannique un imbécile, un type pénible.

La page de manuel entretient la blague : git y est décrit comme « the stupid content tracker », et propose plusieurs significations selon votre humeur du moment.
