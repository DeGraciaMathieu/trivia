En 1928, IBM sort la carte perforée à trous rectangulaires : 80 colonnes, une par caractère. Ce format devient le standard mondial du traitement de données pendant quarante ans. Une ligne de code = une carte = 80 caractères.

Quand arrivent les terminaux à écran, les constructeurs reproduisent la contrainte pour rester compatibles : le VT100 affiche 80 colonnes. Les imprimantes aussi.

Personne n'a jamais mesuré que 80 était la bonne largeur pour lire du code. C'est la largeur d'un carton de 1928, transmise par héritage.
